# Simple AI Inference Analyzer

Aplikasi Python mudah untuk membaca, menapis, menganalisis dan memvisualisasikan data inferens AI.

## Objektif

- Membaca data CSV menggunakan pandas.
- Menapis data berdasarkan nilai confidence.
- Mengira statistik menggunakan NumPy.
- Menghasilkan carta bar menggunakan Matplotlib.
- Mengurus kod menggunakan Git dan GitHub.

## Keperluan

- Python 3.10 atau lebih baharu
- pandas
- NumPy
- Matplotlib

## Pemasangan

```
pip install -r requirements.txt
```

## Menjalankan aplikasi

```
python main.py
```

## Output

- output/filtered_data.csv
- output/object_count.png
